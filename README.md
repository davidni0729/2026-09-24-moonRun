# 嫦娥奔月大賽｜手機體感互動遊戲

通用的中秋派對遊戲，適合朋友聚會、公司活動與社群同樂。五位玩家掃碼加入、直接自拍成為嫦娥，搖晃手機前進，在大屏上競速並回答五道中秋與月亮常識題。

## 公開入口

- [遊戲首頁](https://davidni0729.github.io/2026-09-24-moonRun/)
- [現場大屏](https://davidni0729.github.io/2026-09-24-moonRun/display.html)
- [手機加入](https://davidni0729.github.io/2026-09-24-moonRun/play.html)

GitHub Pages 提供首頁和入口；多人同步、相機照片與主持人控制由 Node.js 服務處理。Pages 本身不執行遊戲伺服器。

## 怎麼玩

1. 主持人在電腦打開大屏，投影或全螢幕顯示。
2. 玩家用手機掃描 QR 碼，填暱稱、允許相機並直接自拍。
3. 開啟動作感應，按「我準備好了」。五人到齊後，主持人開始比賽。
4. 倒數三秒後，左右輕搖手機前進；沒有點按前進模式。
5. 每一段路終點出現二選一題目，限時 12 秒。答對顯示獎勵兩秒並獲得下一段助力；答錯或逾時原地暈眩兩秒。
6. 完成五道題後登月；全員完成或比賽達 150 秒時結算。已完成者優先依完成時間排名，再比較答對數與答題時間。
7. 主持人按「重開下一輪」，再次確認後清空本輪並重新開放加入。

單人測試：至少一支手機加入後，主持人按單人測試按鈕即可略過五人與準備門檻。後臺也提供示範、暫停和繼續。

## 五道通用題

| 題目 | 正確答案 |
| --- | --- |
| 中秋節在農曆哪一天？ | 八月十五 |
| 月亮的光主要來自哪裡？ | 反射太陽光 |
| 月球是地球的什麼？ | 天然衛星 |
| 中秋傳說中，玉兔在月宮做什麼？ | 搗藥 |
| 太陽屬於哪一種天體？ | 恆星 |

可在 `game.mjs` 的 `questions` 更換題目。保留五題、每題兩個選項，`correct` 填正確選項的索引 0 或 1。玩家看到的選項順序會隨機排列。

## 本機啟動

需要 Node.js 20 以上。

```sh
npm ci
npm start
```

啟動訊息提供大屏、手機及含管理金鑰的主持人連結。管理金鑰請只提供給主持人；重新啟動伺服器後請使用新連結。

手機相機和動作感應需要可信任的 HTTPS 網址，並允許相關權限。正式活動請使用部署後的 HTTPS 入口；一般手機不能透過區網 HTTP 位址使用完整感應功能。本機 localhost 主要供桌面開發測試。

## 部署

使用根目錄的 `Dockerfile` 部署 Node.js 服務，健康檢查路徑為 `/healthz`。服務需要支援持續的 SSE 連線。

- `PORT`：服務監聽埠。
- `PUBLIC_BASE_URL`：公開 HTTPS 網址，用來產生手機 QR 碼。
- `site-config.json`：GitHub Pages 首頁網址和實際遊戲服務網址。

推送到 `main` 後，GitHub Actions 會建置並發佈 Pages。手動建置：

```sh
node scripts/build-pages.mjs
```

輸出在 `pages-site/`。更新遊戲伺服器時也須確認雲端服務已部署最新提交。

目前採單一服務、單一房間、記憶體狀態，不適合直接擴增多個實例。重啟會清空本輪。免費雲端方案可能休眠，活動前請先開啟並完整試玩。

## 驗證

```sh
npm test
```

`test/` 另有瀏覽器測試，涵蓋五人完成五題、手機自拍與感應、答錯暈眩、單人測試、大屏版面及後臺重開下一輪。這些測試會重置指定服務的遊戲狀態，請使用測試環境。

設定 `TEST_BASE_URL`、`HOST_KEY` 和 `PLAYWRIGHT_MODULE` 後，可執行個別 `.mjs` 瀏覽器測試。自動測試使用模擬相機和感應事件；正式活動仍應用實際手機檢查權限與搖晃手感。

## 照片與資料

自拍傳送至遊戲伺服器，用於本輪角色呈現，不需要外部 AI 處理。玩家及照片資料儲存在伺服器記憶體；重開下一輪或重啟服務會清除伺服器中的本輪資料。
