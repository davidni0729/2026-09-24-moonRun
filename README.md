# 嫦娥奔月大賽 · 清溪扶輪

五人同場的中秋互動遊戲開發版。手機自拍加入，只用搖晃前進，完成五道清溪知識題後登月。大屏、手機、工作人員控台分離，中央伺服器統一判定進度、答案、倒數與排名。

## 啟動

安裝 Node.js 20 或以上，於本資料夾執行：

```sh
npm install
npm start
```

預設使用 3780 埠，也可設定 `PORT`。不需資料庫，QR Code 由本機套件產生，不依賴外部圖片服務。

- 大屏：`http://localhost:3780/display`，按 F 切換全螢幕。
- 手機：掃描設定好 HTTPS 網址的大屏 QR Code，啟用動作感應後加入。
- 控台：使用啟動訊息中帶 `key` 的專屬 `/host` 連結。每次重啟產生新金鑰，不要分享給玩家。
- 控台的「一鍵五人示範」可用虛擬玩家跑完整場；需先清空本輪。

## 已實作

- 五個參賽名額、暱稱、上傳／拍照選圖、自動中央裁切、自拍套入角色。
- 每位玩家獨立連線與準備，五人準備後倒數開跑。
- 五條固定跑道與角色進度、手機即時狀態、兩個選項隨機排列。
- 每次動作 4 步，採計間隔至少 333ms。每段 100 步，共五段。
- 每題 12 秒。答對顯示 2 秒，下一段加 20 步；錯誤或逾時原地暈眩 2 秒，期間不能前進。
- 第五題回饋結束才登月；本輪最多 150 秒，全員登月可提前結算。
- 完成者按 0.1 秒時間區間、答對數、累計答題時間排序；完全相同並列。
- 未登月者按完成關卡、當段步數、答對數排序。
- 控台暫停／恢復、開賽前移除玩家、重開下一輪。斷線不再採計動作，原頁重連保留進度。
- 原照與成績只暫存在記憶體，重開本輪／關閉伺服器即清除，不上傳外部服務。

## 題庫

`game.mjs` 的 `questions`：年度主題「創造持衡的影響力」、三大支柱、例會新朋友 KPI、Kate 社長 18 歲趣味題、邀請新朋友。前四題採使用者提供內容，第五題採討論補題。年齡題為活動遊戲設定。

## 測試

```sh
npm test
```

`test/browser.mjs` 可用 Playwright 同時開五個獨立瀏覽器環境完成一整輪。執行前設定 `HOST_KEY` 為目前啟動產生的控台金鑰；測試會清空當前場次，請勿在活動中執行。可安裝 Playwright 後執行 `node test/browser.mjs`。

## 開發版限制與下一階段

這是可連線試玩的第一版，尚未部署為正式活動網站。

1. **HTTPS 與手機實測**：手機入場必須先啟用動作感應；一般區網 HTTP 無法使用感應，請使用 HTTPS。iPhone 動作感應與相機權限須在 HTTPS 下測試，不能以桌機測試代替。跨 Wi-Fi／AP 隔離也需現場確認。
2. **視覺素材**：目前重用一個 AI 示意嫦娥角色，自拍採固定圓形裁切覆蓋。正式五色角色、去背、臉部調整、奔跑動作與月宮特效待美術製作。
3. **入場與合照**：大屏首頁已提供 QR Code 與五人即時入場狀態。房間碼、合照下載與多輪活動管理待接入。
4. **正式容錯**：尚未加上多玩家離線警示、恢復前 3 秒倒數、伺服器重啟恢復。現在控台恢復會立即繼續。
5. **操作品質**：準備按鈕目前為人工確認，尚無完整的 5 秒感應校正。動作方向與不同手機靈敏度須實機校準。
6. **部署安全**：目前定位於受控區網彩排。公開部署前需 HTTPS、輸入／請求限制、網路與照片清理政策確認。

`docs/` 保存清溪五題簡報，`progress.md` 保存開發與驗證記錄。

若以固定網域或 HTTPS 部署，請設定 `PUBLIC_BASE_URL`（例如 https://game.example.com），QR Code 會指向該網域的 /play。區網模式自動使用電腦 IP，手機須連同一 Wi-Fi。

## HTTPS 手機測試

目前使用 Cloudflare Quick Tunnel 暫時連回本機 3780 埠，電腦、遊戲伺服器與 tunnel 都必須保持執行。重新建立 tunnel 時網址會改變，需要同步設定 PUBLIC_BASE_URL 並重新啟動伺服器。

```sh
.tools/cloudflared tunnel --url http://127.0.0.1:3780 --no-autoupdate
# 另一個終端，填入上一步實際產生的 HTTPS 網址：
PUBLIC_BASE_URL=https://your-generated-name.trycloudflare.com npm start
```

Quick Tunnel 不支援 SSE，因此 trycloudflare.com 手機頁使用依序短輪詢，區網大屏保留 SSE。可加 `?transport=poll` 測試輪詢模式。8 秒未收到輪詢視為離線。測試通過 HTTPS 安全環境、QR 解碼、加入／準備同步、模擬 motion 事件前進；實體手機感應仍需現場測試。

正式長期網址需要部署 Node 後端。GitHub 用於儲存程式，GitHub Pages 只能放靜態前端，不能直接執行此多人遊戲的後端。

## 真人單人測試

1. 手機掃大屏 QR Code 加入，先開啟搖晃感應。
2. 工作人員打開當次啟動產生的控台網址，點「直接開始（單人測試）」。
3. 至少一位真人玩家已連線即可開始，略過滿五人及準備檢查，倒數 3 秒後開玩。
4. 測試沿用五題、答錯暈眩 2 秒、登月與排名規則。空場無法開始。

「五人開始比賽」保留正式規則。「一鍵五人示範」是自動假玩家演示，與真人單人試玩不同。首頁原樣使用使用者提供的清溪扶輪 Logo，保留原色、完整文字與比例。
